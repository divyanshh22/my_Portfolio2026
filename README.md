# Divyansh's Portfolio Website

This is my personal portfolio — the place where I show off the stuff I've been building. It's a one-page site with a hero section, about me, my skills, education, projects, certificates, and a contact form. Everything runs on plain HTML, CSS, and JavaScript, so it's fast and easy to host anywhere.

## Live

The site is live at: [https://divyansh-portfolio-cxgb.onrender.com/](https://divyansh-portfolio-cxgb.onrender.com/)

## What's inside

- **Hero** – a quick intro with a typing effect and particle background
- **About** – a short background plus an animated tech-orbit around my avatar
- **Skills** – the languages, frameworks, and tools I work with
- **Education** – my academic journey so far
- **Projects** – a selection of things I've built, with links to code and demos
- **Certificates** – some of the courses I've completed
- **Contact** – a small form that mails me directly
- There's also a dark mode (the only mode, really), background music you can toggle, and a working 404 page

## Running it locally

Just clone the repo and open `index.html` in a browser. No build step, no dependencies to install.

```
git clone https://github.com/divyanshh22/my_Portfolio2026.git
cd my_Portfolio2026
```

Then open `index.html`.

## Built with

- HTML / CSS / JavaScript (vanilla, no frameworks)
- jQuery
- Particles.js, Typed.js, ScrollReveal, VanillaTilt
- Font Awesome icons
- EmailJS for the contact form
